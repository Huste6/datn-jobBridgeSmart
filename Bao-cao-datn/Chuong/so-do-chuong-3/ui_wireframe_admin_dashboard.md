# Mô tả Wireframe: Dashboard dành cho Quản trị viên (Admin)

## Tên file đích cần lưu

## Ý đồ thiết kế (Wireframe Layout)
Bản phác thảo trang quản trị hệ thống của Admin:
- **Sidebar bên trái:** Chứa các mục điều hướng "Thống kê", "Quản lý User", "Quản lý Company".
- **Khu vực chính bên phải:**
  - **Hàng các thẻ số liệu (Metrics Cards):** 3 hộp chữ nhật nằm ngang thể hiện: "Tổng số User", "Số Công ty chờ duyệt", "Tin tuyển dụng hoạt động". Mỗi hộp có một con số lớn ở giữa.
  - **Bảng danh sách công ty chờ duyệt (Pending Approval Table):** Hiển thị tên công ty, mã số thuế, và cột thao tác có hai nút xám "Approve" (Duyệt) và "Reject" (Từ chối).
